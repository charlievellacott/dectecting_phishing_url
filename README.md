What I did
I build a classification model that does exactly what Netcraft did. I began with a dataset from Kaggle, cleaned it, split it into training and testing data then looked for patterns/correlations in the format/lengths of different parts of the URL. I used urllib to parse the URL and split it into the different parts; before engineering some basic features. I extended the features by defining, cross-validating and training an n-grams model. I then saved the dataframes (basic features, URLs and labels), matrices (sparce numpy matrices for the n-gram weights), the vectorizer and the n-gram matrix columns. I reduced the dimensionality of the sparce matrices using single vector decomposition – this was to protect against the curse of dimensionality and produce a single rich feature set. I then dropped unnecessary columns and prepared the dataset for training by fitting and transforming a standard scaler to the input dataframe, before bundling the training dataframe and matrix together (via np.hstack). I fed this into the MLPClassifier with hidden layers of size 128 and 64; which after 32 iterations finished training. The MLP model used the ReLU (rectified linear unit) activation function, to reduce computational load, and the optimisation algorithm Adam to improve learning speed and accuracy. 
This was the final model that I produced.
